# Аватар в шапке — дорожка v4

Заменяет `AVATAR_V3.md` целиком. Проект — статический сайт (`index.html`, `css/`, `js/`), не React.

---

## Файлы

Положить в `public/`:

- `avatar-orbit-v4.mp4`
- `avatar-poster-v4.jpg`

| Параметр | Значение |
|---|---|
| Разрешение | 720 × 1222 |
| Длительность | 8.8 секунды, 264 кадра, 30 fps |
| Пропорция | `720 / 1222` |
| Цвет фона | **`#469DC9`** — изменился |
| Keyframe | каждые 5 кадров |

Файлы v3 можно удалить после проверки.

## Изменение в вёрстке

**Цвет фона шапки** — `#469DC9` вместо прежнего `#499AC8`.

Расположение прежнее: **аватар справа, текст слева.** В покое персонаж смотрит влево, в сторону текста.

---

## Что изменилось против v3

- Дорожка снята через Motion Control по референсу с живой съёмкой, поэтому все четыре стороны пройдены с одинаковой амплитудой. Раньше вправо персонаж доворачивал заметно слабее.
- Глаза открыты по всему кругу. В нижнем секторе веки приопущены, но глаза видны — это осознанный компромисс, полностью открыть их в наклоне вниз не удалось ни в одной генерации.
- Скорость по кругу ровнее: разброс 4.8× против почти 10× у отбракованных дублей.
- Круг замыкается почти точно: между последним и первым кадром 2 градуса по направлению взгляда.
- Все значения `MAP` пересняты. Старые к этому файлу не подходят.

## JS — заменить блок скраба целиком

```js
(function () {
  var box = document.getElementById('avatarBox');
  var video = document.getElementById('avatarVideo');
  if (!box || !video) return;

  var DURATION = 8.8;      // длительность дорожки, секунды
  var EASE = 0.1;          // инерция: меньше — взгляд догоняет ленивее
  var AR = 720 / 1222;     // пропорция видео

  // Направление взгляда в градусах -> позиция на дорожке 0..1.
  // Градусы экранные: 0 вправо, 90 вниз, 180 влево, -90 вверх.
  // Углы строго по убыванию. Значения сняты покадрово с готового файла:
  // положение губ отслежено по всем 264 кадрам, эллипс подогнан по МНК,
  // четыре кардинальные точки выверены визуально. Не выводить формулой —
  // скорость по кругу неравномерная.
  var MAP = [
    [  180, 0.0000 ],
    [  135, 0.1324 ],
    [   90, 0.2300 ],
    [   45, 0.3452 ],
    [    0, 0.4331 ],
    [  -45, 0.5741 ],
    [  -90, 0.7301 ],
    [ -135, 0.8343 ],
    [ -180, 1.0000 ]
  ];

  var REST = 0.0441;       // взгляд влево — состояние покоя

  function angleToPos(deg) {
    if (deg > 180) deg -= 360;          // приводим к диапазону таблицы
    if (deg > 180) deg = 180;
    if (deg < -180) deg = -180;
    for (var i = 0; i < MAP.length - 1; i++) {
      var a = MAP[i], b = MAP[i + 1];
      if (deg <= a[0] && deg >= b[0]) {
        return a[1] + (b[1] - a[1]) * ((a[0] - deg) / (a[0] - b[0]));
      }
    }
    return REST;
  }

  // точка отсчёта — глаза персонажа внутри РЕАЛЬНОЙ области видео,
  // а не внутри блока: при object-fit: contain блок может быть больше
  // видео, и отсчёт от блока даёт систематическую ошибку угла
  function eyePoint() {
    var r = box.getBoundingClientRect();
    var vw, vh;
    if (r.width / r.height > AR) { vh = r.height; vw = vh * AR; }
    else                         { vw = r.width;  vh = vw / AR; }
    return {
      x: r.left + (r.width  - vw) / 2 + vw * 0.56,
      y: r.top  + (r.height - vh) / 2 + vh * 0.23
    };
  }

  var still = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  var canHover = window.matchMedia('(hover: hover)').matches;

  // на тач-устройствах курсора нет — крутим дорожку в цикле
  if (!canHover || still) {
    video.loop = true;
    video.play().catch(function () {});
    return;
  }

  video.pause();

  var target = REST;
  var current = REST;

  video.addEventListener('loadedmetadata', function () {
    video.currentTime = REST * DURATION;
  }, { once: true });

  window.addEventListener('mousemove', function (e) {
    var p = eyePoint();
    var deg = Math.atan2(e.clientY - p.y, e.clientX - p.x) * 180 / Math.PI;
    if (deg < 0) deg += 360;
    target = angleToPos(deg);
  }, { passive: true });

  function loop() {
    // кратчайшая дуга: из 0.98 в 0.02 короче через край,
    // а не назад через всю ленту
    var diff = target - current;
    if (diff > 0.5) diff -= 1;
    if (diff < -0.5) diff += 1;
    current = (current + diff * EASE + 1) % 1;

    if (video.readyState >= 1) {
      var t = current * DURATION;
      if (isFinite(t)) {
        video.currentTime = Math.min(DURATION - 0.001, Math.max(0, t));
      }
    }

    requestAnimationFrame(loop);
  }
  requestAnimationFrame(loop);
})();
```

## Известное ограничение

Дорожка не замкнута попиксельно: первый и последний кадр — две отдельные отрисовки одной позы, различаются волосами и фактурой вельвета. Это свойство генеративного видео, а не ошибка сборки.

При пересечении курсором направления «строго влево» относительно лица виден скачок длиной в один кадр. Кратчайшая дуга в `loop()` обязательна — без неё вместо скачка голова делает полный оборот.

Важное отличие от прошлых версий: по направлению взгляда стык составляет всего 2 градуса, то есть голова на нём практически не смещается. Видна только смена фактуры волос и ткани на один кадр, без рывка позы. В v3 на стыке был разрыв около 30 градусов, и голова заметно дёргалась.

Сшивать стык кроссфейдом или морфингом по оптическому потоку пробовали, оба дают двоение лица. Не тратить на это время.

## Настройка после запуска

| Симптом | Что менять |
|---|---|
| Взгляд систематически не доходит по всем четырём точкам | правая колонка `MAP` — сдвинуть все значения на одну величину |
| Промах только в одном секторе | узел `MAP` для этого сектора |
| Промах зависит от близости курсора к аватару | `0.56` и `0.23` в `eyePoint()` |
| Догоняет слишком резко | `EASE` уменьшить до 0.06 |
| Догоняет слишком вяло | `EASE` увеличить до 0.18 |

Менять по одному значению за раз.

---

## Проверка перед сдачей

1. Курсор строго справа от лица → поворот вправо
2. Курсор строго снизу → голова опущена, глаза видны
3. Курсор строго слева → профиль влево
4. Курсор строго сверху → голова запрокинута вверх, глаза открыты
5. Границ прямоугольника видео не видно ни в одном кадре
6. При пересечении направления «строго влево» — скачок на один кадр, но не полный оборот головы
7. Медленно сжать окно от широкого до узкого — вёрстка не ломается
8. На узком экране колонки встают в стопку, аватар сверху
9. На телефоне дорожка крутится сама по себе в цикле

## Чего делать не нужно

- Не ставить `autoplay` и `loop` на десктопе
- Не пережимать `avatar-orbit-v4.mp4` — в нём уплотнены keyframe и выровнен фон
- Не убирать кратчайшую дугу из `loop()`
- Не пересчитывать `MAP` формулой
- Не считать точку отсчёта от `getBoundingClientRect()` напрямую — только через `eyePoint()`
- Не менять `aspect-ratio`
- Не задавать `min-height: 100vh` для `.hero`
- Не накладывать текст поверх аватара — фон видео непрозрачный
