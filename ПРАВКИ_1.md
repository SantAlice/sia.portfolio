# Правки: стекло, подложка, шапка

Три вещи: (1) появляется фоновая картинка-подложка, (2) блоки становятся
по-настоящему полупрозрачными, (3) чинится вертикальная раскладка шапки.

---

## 1. Файлы

| файл | куда положить |
|---|---|
| `bg.webp` | `public/img/bg.webp` |
| `grain.png` | `public/img/grain.png` |

Обе картинки уже подготовлены: размытие и затемнение **запечены в файл**.
В CSS `filter: blur(...)` на подложку **не вешать** — это дорогая операция на
всю площадь экрана, а результат тот же. Если в проекте уже есть правило
`.page-bg { filter: blur(90px) ... }` — удалить его.

## 2. Подложка

```css
.page-bg {
  position: fixed; inset: 0; z-index: -2;
  background: var(--ground) url("../img/bg.webp") center / cover no-repeat;
}
.page-bg::after {                      /* зерно */
  content: ""; position: absolute; inset: 0;
  background: url("../img/grain.png") repeat;
  opacity: .07; mix-blend-mode: overlay;
  pointer-events: none;
}
```

`.page-bg` — пустой `<div class="page-bg"></div>` первым элементом в `<body>`.
`body` оставить с `background: var(--ground)` как запасной цвет.

## 3. Почему блоки не выглядели стеклянными

Две причины, обе устраняются здесь:

1. **Под ними ничего не было.** Подложка была залита сплошным `--ground`.
   Полупрозрачность поверх однородной заливки визуально неотличима от
   непрозрачной — просвечивать нечему. Теперь под блоками картинка.
2. **Непрозрачность 78–82 % — это почти сплошная заливка.** Стекло начинает
   читаться примерно с 65 %.

Новые значения (замерены в браузере, не на глаз):

```css
:root {
  --ground: #0E2634;
  --teal:   #184860;
  --blue:   #286284;   /* было #3880A8 — затемнено ради контраста, см. ниже */
  --ink:    #103040;
  --gap:    28px;      /* было 18px */
  --radius: 32px;
}

.section {
  margin-bottom: var(--gap);
  border-radius: var(--radius);
  position: relative; overflow: hidden;
  backdrop-filter: blur(26px) saturate(115%);
  -webkit-backdrop-filter: blur(26px) saturate(115%);
}
.section--teal { background: rgba( 24, 72,  96, .66); }
.section--blue { background: rgba( 40, 98, 132, .62); }
.section--ink  { background: rgba( 16, 48,  64, .72); }
```

Внешние поля — чтобы подложки было видно больше:

```css
.page { padding: var(--gap) clamp(var(--gap), 3.2vw, 56px); }
```

Волосковую линию `.section::before` оставить, но поднять до
`rgba(255,255,255,.15)`: на полупрозрачной карточке край теряется сильнее.

### Про `--blue`

`#3880A8` при 60 % на этой подложке даёт для основного текста контраст
**3.55:1** при норме 4.5:1 — текст на светло-синих карточках не проходит.
`#286284` при 62 % даёт **4.69:1** для текста и **5.20:1** для заголовка.
Разница между teal и blue при этом сохраняется, чередование работает.

Заодно поднять непрозрачность основного текста с `.86` до `.92` —
на стекле разница видна.

## 4. Шапка: раскладка сломана

На текущей сборке список `AI-ВИЗУАЛИЗАЦИЯ / ФОТО И ВИДЕО ДЛЯ БРЕНДОВ / …`
начинается от самого верха карточки и наезжает на логотип «НАСТЯ / AI-креатор».
Первый пункт вообще уехал за верхний край.

Причина: колонка контента выровнена по верху карточки и не учитывает
фиксированную шапку.

```css
.hero__content {
  position: relative; z-index: 3;
  padding-top: clamp(104px, 15vh, 170px);   /* высота фикс-шапки + воздух */
}
.hero__list { margin: 0; padding: 0; list-style: none; }
.hero__list li {
  font-family: "Manrope", system-ui, sans-serif;
  font-weight: 600; text-transform: uppercase; letter-spacing: .02em;
  font-size: clamp(24px, 1.9vw, 34px);
  line-height: 1.28;
  color: rgba(247,241,223,.82);
}
.hero__title { margin-top: clamp(36px, 7vh, 90px); }
```

Проверка: при ширине 1900 px первый пункт списка начинается **ниже** нижней
границы логотипа, между списком и заголовком есть пустое поле, и заголовок
попадает примерно в вертикальную середину карточки.

## 5. Размер шапки

Уменьшить высоту карточки: `height: calc(82svh - var(--gap))` вместо `88svh`.
Видео с `object-fit: contain` уменьшится вместе с ней — персонаж перестанет
занимать пол-экрана.

## Чек-лист

1. `bg.webp` реально грузится — в DevTools → Network есть запрос и он 200.
2. Правила `filter: blur(...)` на `.page-bg` нет.
3. В зазорах между карточками видна цветная подложка, а не ровный тёмный цвет.
4. Сквозь карточку видно неравномерность фона: один край светлее другого.
5. Соседние карточки различаются по цвету.
6. Контраст основного текста на `--blue`-карточке ≥ 4.5:1 — замерить.
7. Первый пункт списка в шапке не перекрывается логотипом на 1440 и 1920 px.
8. Между списком и заголовком в шапке есть пустое поле.
