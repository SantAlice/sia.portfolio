# Шапка сайта — сборка на подложке

Заменяет собой все предыдущие задания и правки. Старые файлы (`ЗАДАНИЕ_ШАПКА.md`,
`ПРАВКИ*.md`, `AVATAR_*.md`) отменены, их можно удалить.

Эталон — **`итог_шапка.png`**, снят на окне 1897×915.

## Структура проекта

```
Nastya ai creator/          ← корень, здесь index.html
├── css/                    ← файл стилей здесь
├── js/                     ← скрипты здесь
├── public/{fonts,img,video}
└── index.html
```

`public/` — обычная папка проекта, не корень сайта. Сборщика нет.
Пути только относительные, **ведущий слэш не ставить**. Из `css/style.css`
путь до ассетов начинается с `../public/`.

## Главное изменение: сайт уходит на подложку

Весь контент живёт в скруглённых карточках на тёмном фоне страницы. Верхнее меню
сайта переезжает **внутрь** карточки шапки — отдельной полосой над ней оно
разламывает всю идею.

```css
:root {
  --ground: #16394D;   /* фон страницы под карточками */
  --bg:     #3D84A8;   /* карточка шапки, совпадает с фоном видео */
  --cream:  #F7F1DF;
  --ink:    #0F1720;
  --pink:   #F4A9BE;
  --gap:    18px;      /* поле подложки */
  --radius: 30px;
}

body { margin: 0; background: var(--ground); }

.hero {
  position: relative;
  margin: var(--gap);
  height: calc(88svh - var(--gap));
  min-height: 620px;
  border-radius: var(--radius);
  overflow: hidden;
  background: var(--bg);
}
```

Высота 88svh, а не 100 — снизу должен выглядывать край следующей секции. Это и
подсказывает скролл, и дополнительно уменьшает шапку.

Следующая секция — такая же карточка с полем `var(--gap)` и тем же скруглением,
но кремовая (`#F2ECDC`), чтобы задать ритм чередования.

## Видео

```html
<video class="hero__video" muted playsinline preload="auto"
       poster="public/img/hero-poster.webp"
       data-src-sd="public/video/hero-mobile.mp4"
       data-src-hd="public/video/hero.mp4"></video>
```

```css
.hero__video {
  position: absolute; inset: 0; width: 100%; height: 100%;
  object-fit: contain;            /* кадр целиком, персонаж не увеличивается */
  object-position: 50% 100%;
  transform: scale(1.004);        /* убирает волосок передискретизации по кромке */
  transform-origin: bottom center;
}
```

```js
const hero  = document.querySelector('.hero');
const video = document.querySelector('.hero__video');

if (video && !window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
  const px = window.innerWidth * (window.devicePixelRatio || 1);
  video.src = video.dataset[px > 1400 ? 'srcHd' : 'srcSd'];
  video.play().catch(() => {});

  hero.addEventListener('mouseenter', () => {
    if (!video.paused) return;
    video.currentTime = 0;
    video.play().catch(() => {});
  });
}
```

Скрипт ставится сразу после разметки секции — не в конце `body` и не внутри
`DOMContentLoaded`, иначе постер сменится рывком.

.hero__panel {

  width: clamp(320px, 42vw, 730px);
  padding: clamp(22px, 2.2vw, 34px);
}

.hero__glass {
  position: absolute;
  inset: -22% -12%;              /* слой шире панели — растушёвка уходит наружу */
  border-radius: 0;              /* радиуса быть не должно: он и рисует контур */
  background: radial-gradient(closest-side,
      rgba(8,32,48,.62), rgba(8,32,48,.34) 55%, rgba(8,32,48,0) 100%);
  backdrop-filter: blur(20px) saturate(112%);
  -webkit-backdrop-filter: blur(20px) saturate(112%);
  -webkit-mask-image: radial-gradient(closest-side, #000 62%, transparent 100%);
          mask-image: radial-gradient(closest-side, #000 62%, transparent 100%);
}
.hero__copy { position: relative; }

@supports not (backdrop-filter: blur(1px)) {
  .hero__glass { background: radial-gradient(closest-side,
      rgba(8,32,48,.80), rgba(8,32,48,.50) 55%, rgba(8,32,48,0) 100%); }

`closest-side` здесь принципиально: при радиусе в процентах растушёвка уходит за
пределы элемента, внутри маска остаётся сплошной, и край рисует `border-radius` —
получается чёткая рамка. Проверено в браузере.

## Жёсткие требования — не нарушать

**Не ставь `loop` на видео.** Первый и последний кадры не совпадают,
зацикливание даёт видимый рывок.

**Не ставь `autoplay` в разметке.** Запуск делает скрипт после выбора источника.

**Не убирай `muted` и `playsinline`** — без них не будет автозапуска в Safari на iOS.

**Не удаляй `text-shadow`** у `.hero__nav a` и у `.header`. Под этими надписями
проходит светлая ладонь; без тени контраст падает до 1.10:1. Это не декор.

**Не опускай кегль навигации ниже 24 px на десктопе.** Полужирный гротеск
с трекингом и тенью читается поверх ладони начиная примерно с 22 px, обычное
начертание на 13–23 px не читается вовсе. 16 px — только для мобильного.

**Не меняй `object-fit: contain` на `cover` на десктопе.** `contain` показывает
кадр целиком; при `cover` браузер режет верх и низ и увеличивает персонажа
на 15–20%.

**Не добавляй `border-radius` к `.hero__glass`** и не меняй `closest-side` на
проценты — именно из-за этого появлялась чёткая рамка.

**Не расширяй `.hero__panel` шире `42vw` / `730px`** — лицо персонажа начинается
с 45% ширины кадра.

**Не применяй Soledago нигде, кроме `h1`.**

**Не пережимай и не конвертируй видеофайлы.** Они собраны из утверждённого
исходника, фон вычищен, битрейт подобран.

## Чек-лист приёмки

Отчитайся по каждому пункту отдельно.

1. Границы видео внутри карточки не видно: пипеткой сверить пиксель внутри кадра
   и по бокам от него — с обеих сторон `#3D84A8`.
2. Карточка шапки не касается краёв окна, поле `18px` со всех сторон, снизу
   выглядывает край следующей секции.
3. Верхнее меню внутри карточки, логотип и пункты читаются в момент прохода ладони.
4. У панели нет края ни на светлой ладони, ни на тёмных волосах.
5. Список направлений читается поверх ладони. Проверять покадрово, не по постеру.
6. Список и панель не пересекаются ни на одной ширине от 360 до 2560.
7. Заголовок всегда в две строки, не выходит за панель.
8. Панель не наезжает на лицо на 1920 / 1440 / 1280 / 390.
9. Контраст подзаголовка на панели ≥ 4.5:1 — замерить инструментом.
10. Видео замирает на позе с персонажем, а не на пустом фоне.
11. В Network загружается `hero.mp4` при `innerWidth × devicePixelRatio > 1400`.
12. Веснушки на щеке различимы на паузе в полный экран.
13. На странице ровно два шрифта: Soledago и Manrope. Onest удалён.
14. Открыть `index.html` через `file://` без сервера — всё подгружается.
15. `prefers-reduced-motion: reduce` — видео не играет, постер на месте.
