# Аватар в шапке — дорожка v8

Заменяет v7. Новый исходник и два новых поведения: **возврат в нейтраль при простое**
и **явный неотслеживаемый сектор сверху**. Все числа другие — значения из v7 не подойдут.

Проект — статический сайт (`index.html`, `css/`, `js/`), не React.

---

## Что нового по сравнению с v7

1. **Другая дорожка.** 585 кадров, 60 fps, 9.75 секунды. `MAP` пересчитан целиком.
2. **Возврат при простое.** Если мышь не двигалась дольше 3 секунд — персонаж
   плавно возвращается в нейтральную позу и смотрит вперёд. Так же он реагирует
   на уход курсора за пределы окна.
3. **Неотслеживаемый сектор стал больше.** В этом исходнике голова не заходит
   выше уровня глаз слева. Покрыто 227° из 360°, не покрыто 133° сверху.

## Про подключение видео

Видео подключается обычной ссылкой на файл в `public/`.
**Не вшивать его в HTML как `data:` URI** — это 7 МБ base64 внутри разметки,
страница не отрисуется, пока они не скачаются и не распарсятся, и браузер
не сможет их закешировать.

## Что дорожка отслеживает, а что нет

Градусы экранные: 0 вправо, 90 вниз, 180 влево, 270 вверх. Отсчёт — от глаз
персонажа к курсору.

- **Покрыто: 318° → через 0° → 185°.** То есть вверх-вправо, вправо,
  вниз-вправо, вниз, вниз-влево, влево. 227° из 360°.
- **Не покрыто: 185° → 318°.** Вверх, вверх-влево, вверх-вправо. 133°.

Это не недоработка, а свойство исходника: в нём голова уходит вправо, проходит
по нижней дуге и приходит влево, но выше уровня глаз не поднимается. В непокрытом
секторе персонаж возвращается в нейтраль — ровно то поведение, которое нужно.

Отдельно стоит понимать, что сектор широкий: нейтраль включается не только когда
курсор строго сверху, но и когда он выше уровня глаз слева — то есть в шапке сайта
и в верхней части заголовка. Если это будет мешать, единственный способ сузить
сектор — снять новый исходник, где голова доходит до верхней дуги.

Расположение: **аватар справа, текст слева.**

## Состояние покоя

`avatar-poster-v8.jpg` — ровно первый кадр дорожки: фронтальная поза, взгляд
в камеру. До первого движения мыши постер и первый кадр видео совпадают
пиксель в пиксель.

Возврат в нейтраль — и по простою, и из непокрытого сектора — идёт по настоящим
кадрам исходника: слева через кадры 501–584, справа через 48–0 в обратную сторону.
Это не кроссфейд и не подстановка.

Секция с аватаром обязана иметь фон `--hero-bg` на всю ширину блока с видео.

**Про цвет отдельно.** Браузер декодирует видео из YUV, и точного совпадения
с CSS-цветом там не бывает само по себе. Поэтому фон внутри mp4 записан не ровно
`#3D84A8`, а на пару единиц синее, и файл размечен как BT.709 / limited range —
после декодирования браузер рисует ровно `#3D84A8`. Отсюда два запрета:
**не менять `--hero-bg`** и **не пережимать mp4** — и то, и другое вернёт
видимый прямоугольник вокруг аватара.

## JS

```js
(function () {
  var box = document.getElementById('avatarBox');
  var video = document.getElementById('avatarVideo');
  if (!box || !video) return;

  var DURATION = 9.75;     // длительность дорожки, секунды
  var EASE = 0.1;          // доля пути за кадр при 60 Гц; меньше — ленивее
  var AR = 720 / 1078;     // пропорция видео
  var STEP = 1 / 120;      // половина кадра при 60 fps
  var IDLE = 3000;         // мышь молчит дольше — уходим в нейтраль, мс

  // Покрытая дуга: направление взгляда -> позиция на дорожке 0..1.
  // Дуга проходит через 0°, поэтому углы развёрнуты в непрерывную
  // шкалу 318..545 (545 = 185 + 360). Значения сняты покадрово —
  // скорость движения по дуге неравномерная. Формулой не выводится.
  var MAP = [
    [ 318.0, 0.0829 ], [ 326.0, 0.1103 ], [ 337.0, 0.1376 ],
    [ 348.0, 0.1718 ], [ 353.0, 0.2060 ], [ 357.0, 0.2402 ],
    [ 365.0, 0.2744 ], [ 383.0, 0.3085 ], [ 395.0, 0.3427 ],
    [ 405.0, 0.3838 ], [ 420.0, 0.4248 ], [ 430.0, 0.4658 ],
    [ 440.0, 0.5068 ], [ 450.0, 0.5479 ], [ 456.0, 0.5889 ],
    [ 470.0, 0.6299 ], [ 484.0, 0.6573 ], [ 500.0, 0.6846 ],
    [ 515.0, 0.7188 ], [ 530.0, 0.7530 ], [ 538.0, 0.7872 ],
    [ 542.0, 0.8214 ], [ 545.0, 0.8556 ]
  ];

  var ARC_LO = 318;        // начало дуги — взгляд вверх-вправо
  var ARC_HI = 545;        // конец дуги — взгляд влево (185° + 360)
  var WEDGE  = 185;        // ниже этого угла разворачиваем шкалу
  var NEUTRAL = 0.0;       // фронтальная поза, первый кадр дорожки

  function angleToPos(deg) {
    // разворачиваем в непрерывную шкалу: дуга идёт через 0°
    var u = deg % 360;
    if (u < 0) u += 360;
    if (u < WEDGE) u += 360;

    if (u >= ARC_LO && u <= ARC_HI) {
      for (var i = 0; i < MAP.length - 1; i++) {
        var a = MAP[i], b = MAP[i + 1];
        if (u >= a[0] && u <= b[0]) {
          return a[1] + (b[1] - a[1]) * ((u - a[0]) / (b[0] - a[0]));
        }
      }
    }
    // верхний сектор 185..318 — его в дорожке нет: идём в нейтраль.
    // К какому её краю — решает кратчайшая дуга в loop(),
    // поэтому голова возвращается той же стороной, откуда пришла.
    return NEUTRAL;
  }

  // точка отсчёта — глаза персонажа внутри РЕАЛЬНОЙ области видео,
  // а не внутри блока: при object-fit: contain блок может быть больше
  // видео, и отсчёт от блока даёт систематическую ошибку угла
  function eyePoint() {
    var r = box.getBoundingClientRect();
    var vw, vh;
    if (r.width / r.height > AR) { vh = r.height; vw = vh * AR; }
    else                         { vw = r.width;  vh = vw / AR; }
    return {
      x: r.left + (r.width  - vw) / 2 + vw * 0.486,
      y: r.top  + (r.height - vh) / 2 + vh * 0.188
    };
  }

  var still = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  var canHover = window.matchMedia('(hover: hover)').matches;

  // на тач-устройствах курсора нет — крутим дорожку в цикле
  if (!canHover || still) {
    video.loop = true;
    video.play().catch(function () {});
    return;
  }

  video.pause();

  var aim = NEUTRAL;       // куда смотреть по курсору
  var current = NEUTRAL;   // где голова сейчас
  var lastMove = -1e9;     // когда мышь двигалась в последний раз
  var last = 0;
  var lastSeek = -1;

  video.addEventListener('loadedmetadata', function () {
    video.currentTime = 0;
  }, { once: true });

  window.addEventListener('mousemove', function (e) {
    lastMove = performance.now();
    var p = eyePoint();
    var deg = Math.atan2(e.clientY - p.y, e.clientX - p.x) * 180 / Math.PI;
    if (deg < 0) deg += 360;
    aim = angleToPos(deg);
  }, { passive: true });

  // курсор ушёл из окна — сразу считаем это простоем
  document.addEventListener('mouseleave', function () {
    lastMove = -1e9;
  });

  // вкладку свернули — не держим позу
  document.addEventListener('visibilitychange', function () {
    if (document.hidden) lastMove = -1e9;
  });

  function loop(now) {
    // мышь молчит дольше IDLE — возвращаемся в нейтраль.
    // Возврат идёт тем же сглаживанием, что и обычное движение,
    // поэтому голова не дёргается, а плавно опускается вперёд
    var target = (now - lastMove > IDLE) ? NEUTRAL : aim;

    // шаг сглаживания считаем от реального времени кадра, а не от его номера:
    // иначе на 120 Гц голова догоняет курсор вдвое быстрее, чем на 60 Гц,
    // а при просадке кадров — рывками
    var dt = last ? Math.min((now - last) / 1000, 0.1) : 1 / 60;
    last = now;
    var k = 1 - Math.pow(1 - EASE, dt * 60);

    // кратчайшая дуга: оба конца дорожки — одна и та же нейтральная
    // поза, поэтому переход через край непрерывен. Не убирать.
    var diff = target - current;
    if (diff > 0.5) diff -= 1;
    if (diff < -0.5) diff += 1;
    current = (current + diff * k + 1) % 1;

    if (video.readyState >= 1) {
      var t = current * DURATION;
      // не дёргать currentTime, пока голова стоит: лишние перемотки
      // заставляют браузер пересобирать кадр и дают микрорывки
      if (isFinite(t) && Math.abs(t - lastSeek) >= STEP) {
        lastSeek = t;
        video.currentTime = Math.min(DURATION - 0.001, Math.max(0, t));
      }
    }

    requestAnimationFrame(loop);
  }
  requestAnimationFrame(loop);
})();
```

## Настройка после запуска

| Симптом | Что менять |
|---|---|
| Слишком быстро уходит в нейтраль при простое | `IDLE` увеличить до 5000 |
| Слишком долго ждёт | `IDLE` уменьшить до 1500 |
| Догоняет вяло | `EASE` увеличить до 0.15–0.2 |
| Догоняет резко, хочется мягче | `EASE` уменьшить до 0.06 |
| Видны ступеньки при медленном движении | `STEP` уменьшить до `1/240` |
| Взгляд систематически не доходит по всей дуге | левая колонка `MAP` — сдвинуть все углы на одну величину |
| Промах в одном секторе | соседние узлы `MAP` для этого сектора |
| Промах зависит от близости курсора к аватару | `0.486` и `0.188` в `eyePoint()` |

Менять по одному значению за раз.

## Проверка перед сдачей

1. Прямоугольника видео не видно ни в одном кадре — фон шапки и фон видео совпадают
2. Курсор строго слева от лица → профиль влево
3. Курсор строго снизу → голова опущена
4. Курсор строго справа → голова повёрнута вправо, глаза открыты
5. Курсор строго сверху → персонаж плавно уходит в нейтраль, без рывка
6. Убрать руки с мыши на 3 секунды → персонаж плавно возвращается в нейтраль
7. Увести курсор за пределы окна → возврат в нейтраль
8. Медленно провести курсором по нижней половине круга — голова идёт ровно,
   без ступенек и без разворотов «через всю голову»
9. Медленно сжать окно от широкого до узкого — вёрстка не ломается
10. На узком экране колонки встают в стопку, аватар сверху
11. На телефоне дорожка крутится сама по себе в цикле

## Чего делать не нужно

- Не вшивать mp4 в HTML как `data:` URI
- Не ставить `autoplay` и `loop` на десктопе
- Не пережимать `avatar-orbit-v8.mp4` — в нём уплотнены keyframe, откалиброван
  под браузер фон и достроены промежуточные кадры
- Не менять `--hero-bg`: фон видео подогнан именно под `#3D84A8`
- Не «дополнять» `MAP` значениями для верхнего сектора — их в дорожке нет
- Не убирать кратчайшую дугу из `loop()`
- Не убирать разворот `if (u < WEDGE) u += 360`
- Не возвращать сглаживание к постоянному шагу — привязка к `dt` тут не украшение
- Не пересчитывать `MAP` формулой
- Не считать точку отсчёта от `getBoundingClientRect()` напрямую — только через `eyePoint()`
- Не менять `aspect-ratio`
- Не накладывать текст поверх аватара — фон видео непрозрачный
