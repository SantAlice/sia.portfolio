# Дизайн-система сайта: блоки на подложке

Дополняет `ЗАДАНИЕ.md` (шапка). Здесь — всё остальное: подложка, карточки,
типографика секций, украшения.

## Что меняется по сути

1. Полосы во всю ширину превращаются в **отдельные карточки на подложке**.
2. Колонка контента расширяется с ~760 до **1200–1280 px**.
3. Заголовки секций переезжают на **Soledago** и становятся **кремовыми**.
4. Курсивный акцент («нельзя», «стои́ло», «не было») убирается.
5. Розовый остаётся только акцентом.

## Подложка

```css
:root {
  --ground:  #0E2634;   /* фон страницы под карточками */
  --teal:    #184860;   /* тёмная карточка */
  --blue:    #286284;   /* светлая карточка */
  --ink:     #103040;   /* карточки цен и сметы */
  --cream:   #F7F1DF;
  --pink:    #E0A8B8;
  --gap:     28px;
  --radius:  30px;
  --col:     1240px;    /* ширина колонки контента внутри карточки */
}

body { margin: 0; background: var(--ground); }
```

Фон — работа из портфолио (девушка на гигантском антуриуме) под размытием
и затемнением. Размытие и затемнение **запечены в файл** `bg.webp`: `filter:
blur()` на всю площадь экрана стоит дорого, а результат тот же.

```css
.page-bg {
  position: fixed; inset: 0; z-index: -2;
  background: var(--ground) url("../img/bg.webp") center / cover no-repeat;
}
.page-bg::after {                  /* зерно */
  content: ""; position: absolute; inset: 0;
  background: url("../public/img/grain.png") repeat;
  opacity: .06; mix-blend-mode: overlay;
}
```

Зерно обязательно: на большой площади размытый градиент полосит, зерно это
скрывает. Файл — тайл 128×128 с монохромным шумом.

## Карточка секции

Каждая секция — отдельная карточка. Между ними ровно `--gap`.

```css
.section {
  margin: var(--gap);
  border-radius: var(--radius);
  padding: clamp(48px, 5vw, 96px) 0;
  position: relative;
  overflow: hidden;
  backdrop-filter: blur(26px) saturate(110%);
  -webkit-backdrop-filter: blur(26px) saturate(110%);
}
.section::before {                 /* волосковая линия по контуру */
  content: ""; position: absolute; inset: 0;
  border-radius: inherit;
  border: 1px solid rgba(255,255,255,.15);
  pointer-events: none;
}
.section__inner { width: min(var(--col), 100% - 96px); margin-inline: auto; }

.section--teal { background: rgba(24, 72,  96, .66); }
.section--blue { background: rgba(40, 98, 132, .62); }
.section--ink  { background: rgba(16, 48,  64, .72); }
```

Волосковая линия — не украшение, а необходимость: когда цвет карточки близок
к фону, без неё края теряются.

### Про непрозрачность

Стекло начинает читаться примерно с 65 %. При 78–82 % (как было) карточка
визуально неотличима от сплошной заливки. Вторая половина условия — под
карточкой должно быть что просвечивать: поверх однородного `--ground`
полупрозрачность не видна вообще, нужна картинка-подложка.

**Чередование обязательно.** Две одинаковые карточки подряд читаются как один
длинный блок, и ритм пропадает. Порядок: teal → blue → teal → blue, карточки
`--ink` только для цен и сметы.

## Типографика

Шрифтов ровно два.

```css
h1, .section__title {
  font-family: "Soledago", "Manrope", system-ui, sans-serif;
  color: var(--cream);
  line-height: .96;
  letter-spacing: 0;
}
.section__title { font-size: clamp(2.2rem, 4.2vw, 68px); margin: 0; }

/* всё остальное — Manrope */
body, p, li, a, .section__label, .btn { font-family: "Manrope", system-ui, sans-serif; }
```

**Soledago только на `h1` и `.section__title`.** В списках, пунктах аккордеона,
названиях тарифов и подписях — Manrope. На кегле 30–40 px дисплейный шрифт
перестаёт сканироваться, глаз читает его как картинку.

Заголовки **кремовые**, не розовые. Замерено: розовый на синей карточке даёт
контраст 2.17:1 при пороге 3:1 для крупного текста. Кремовый на новых
значениях — 5.20:1 на синей карточке и 7.02:1 на teal.

Основной текст — `rgba(247,241,223,.92)`, не `.86`: на полупрозрачной карточке
разница видна. Замерено на синей карточке: 4.69:1 при пороге 4.5:1.

Курсивный акцент убрать. Он был вторым дисплейным шрифтом и с Soledago
не сочетается.

## Надзаголовок

Уже есть на сайте, сохранить как есть — это лучший из существующих приёмов.

```css
.section__label {
  display: inline-block;
  padding: 6px 12px; border-radius: 4px;
  background: var(--pink); color: var(--ink);
  font-weight: 600; font-size: 11px; letter-spacing: .14em; text-transform: uppercase;
}
```

## Украшения

Четыре приёма, больше не добавлять.

**Номер секции.** Крупно в Soledago в правом верхнем углу карточки,
`font-size: 120px`, `color: rgba(247,241,223,.12)`. Даёт ощущение оглавления
и объясняет присутствие дисплейного шрифта.

**Розовый акцент — один на карточку.** Дуга, подчёркивание, номер шага или
заливка кнопки. Два розовых объекта в одной карточке — и розовый перестаёт быть
акцентом.

**Зерно** поверх всего, включая карточки.

**Персонаж-гриб.** Один раз за весь сайт выглядывает из-за края карточки —
например, у блока «Четыре шага». Ассет уже есть, отдельной работы не требует.

Чего не делать: теней под карточками (на размытом фоне грязнят), обводок ярче
15%, иконочных наборов, вторых акцентных цветов.

## Что делать с пустыми местами под картинки

На макете три слота заштрихованы. Пока работ нет — не оставлять пустой штриховкой,
это читается как недоделка. Временное решение: заливка `--ink` с надписью
`СКОРО` в `.section__label`-стиле по центру.

## Чек-лист

1. Между карточками ровно `--gap`, ни у одной секции нет полосы во всю ширину.
2. Соседние карточки не совпадают по цвету.
3. Края карточек различимы на фоне: волосковая линия на месте.
4. Soledago встречается только на `h1` и `.section__title`. Проверить поиском
   по CSS: других правил с этим семейством быть не должно.
5. Все заголовки кремовые. Розовых заголовков на странице нет.
6. Курсивного акцента нигде нет.
7. Колонка контента 1200–1280 px, а не 760.
8. Контраст заголовка к фону карточки ≥ 3:1, обычного текста ≥ 4.5:1 — замерить
   инструментом на каждой секции.
9. Розовый в каждой карточке встречается не больше одного раза, не считая
   надзаголовка.
10. Зерно видно при увеличении, но не видно при обычном просмотре.
