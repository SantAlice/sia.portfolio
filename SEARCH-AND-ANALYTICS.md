# Google, Яндекс: индексация и посещаемость

В коде сайта подготовлены SEO-теги, канонический адрес `https://anastasia.pics/`,
карта сайта, robots.txt и подключение аналитики. Счётчики пока выключены:
их нужно создать в ваших аккаунтах и вписать выданные сервисами идентификаторы.
Пароли от Google и Яндекса передавать не нужно.

Google Analytics и Яндекс Метрика показывают посещаемость.
Google Search Console и Яндекс Вебмастер управляют подтверждением сайта,
индексацией и отчётами о поисковом трафике. Это четыре отдельных сервиса.

## 1. Создать Google Analytics

1. Откройте [Google Analytics](https://analytics.google.com/) и войдите в свой Google-аккаунт.
2. Если Analytics ещё не использовался, нажмите «Начать измерения». Если использовался —
   откройте «Администратор» → «Создать» → «Аккаунт» или «Ресурс».
3. Назовите аккаунт и ресурс, например «Анастасия Куликова — anastasia.pics».
   Выберите свой часовой пояс и валюту отчётов. Для московского времени — Москва.
4. После создания ресурса выберите платформу «Веб».
5. Укажите URL `https://anastasia.pics` и название потока «Портфолио».
6. В сведениях о веб-потоке найдите **идентификатор потока данных вида `G-XXXXXXXXXX`**.
   Нужен именно ID с `G-`, а не числовой номер ресурса или потока.
7. Пришлите этот ID в чат или впишите его в `analytics-config.json`:

   ```json
   {
     "googleMeasurementId": "G-ВАШ_ID",
     "yandexMetrikaId": null
   }
   ```

После публикации настроек откройте сайт и посмотрите в Analytics:
«Отчёты» → «В реальном времени». Блокировщики рекламы могут мешать проверке.
Обычные отчёты обновляются не сразу.

Сайт отправляет события:

- `generate_lead` — клик по Telegram для обсуждения проекта;
- `telegram_channel_click` — клик по кнопке Telegram-канала.

После первого появления события `generate_lead` его можно отметить как ключевое
событие в настройках Analytics. Оно означает клик, а не факт отправки сообщения.

## 2. Создать Яндекс Метрику

1. Откройте [Яндекс Метрику](https://metrika.yandex.ru/) и войдите в свой Яндекс-аккаунт.
2. Нажмите «Добавить счётчик».
3. Название — например «anastasia.pics». Адрес — `https://anastasia.pics`.
4. Выберите часовой пояс. Примите условия сервиса и создайте счётчик.
5. Скопируйте **числовой номер счётчика**, например `123456789`, и пришлите его в чат.
   Или впишите его в поле `yandexMetrikaId` в `analytics-config.json` без кавычек.
6. В настройках счётчика откройте «Цели» → «Добавить цель» → «JavaScript-событие».
   Создайте две цели с точными идентификаторами:

   | Название | Идентификатор |
   | --- | --- |
   | Обсудить проект в Telegram | `telegram_project` |
   | Перейти в Telegram-канал | `telegram_channel` |

После публикации настроек откройте сайт, нажмите Telegram-кнопку и проверьте
появление визита и достижения цели в Метрике. Вебвизор в подготовленном коде выключен;
обычные отчёты посещаемости и цели работают без него.

## 3. Подтвердить сайт в Google Search Console

Этот шаг завершается после запуска рабочего HTTPS на домене.

1. Откройте [Google Search Console](https://search.google.com/search-console).
2. Нажмите «Добавить ресурс».
3. Простой вариант — **«Ресурс с префиксом в URL»**, адрес `https://anastasia.pics/`.
4. В способах подтверждения выберите «HTML-тег».
5. Скопируйте выданный тег `<meta name="google-site-verification" content="…">`
   целиком и пришлите в чат. Он будет добавлен в `<head>` сайта.
6. После публикации тега нажмите «Подтвердить» в Search Console.
7. В разделе «Файлы Sitemap» отправьте `https://anastasia.pics/sitemap.xml`.
8. Вверху вставьте `https://anastasia.pics/`, откройте «Проверку URL» и нажмите
   «Запросить индексирование», если сервис предлагает эту кнопку.

Альтернатива — тип «Доменный ресурс», домен `anastasia.pics`.
Для него Google выдаёт TXT-запись DNS: её нужно добавить в панели управления доменом.
Этот способ подтверждает сразу HTTP/HTTPS и поддомены.

## 4. Подтвердить сайт в Яндекс Вебмастере

1. Откройте [Яндекс Вебмастер](https://webmaster.yandex.ru/).
2. Нажмите «Добавить сайт», укажите `https://anastasia.pics`.
3. Выберите подтверждение **метатегом**.
4. Скопируйте выданный тег `<meta name="yandex-verification" content="…">`
   целиком и пришлите в чат.
5. После публикации тега нажмите «Проверить».
6. В разделе индексирования откройте «Файлы Sitemap» и добавьте
   `https://anastasia.pics/sitemap.xml`.
7. В разделе «Переобход страниц» отправьте `https://anastasia.pics/`.
8. Позже проверяйте «Диагностику», «Страницы в поиске» и отчёты о поисковых запросах.

Подтверждение и отправка Sitemap не гарантируют немедленное появление в поиске:
решение и сроки индексации определяют Google и Яндекс.

## Что прислать для подключения

Достаточно четырёх значений — они не являются паролями:

1. ID Google Analytics `G-…`.
2. Номер счётчика Яндекс Метрики.
3. Метатег подтверждения Google Search Console, если выбран этот способ.
4. Метатег подтверждения Яндекс Вебмастера.

Настройки можно записать одной командой из корня репозитория, заменив примеры:

```sh
python3 scripts/configure-services.py \
  --google 'G-ВАШ_ID' \
  --yandex 123456789 \
  --google-verification 'ТОКЕН_ИЗ_CONTENT_GOOGLE' \
  --yandex-verification 'ТОКЕН_ИЗ_CONTENT_YANDEX'
```

Аргументы с неподготовленными значениями можно опустить. Затем изменения нужно
опубликовать на сервере. Само создание сервисов в аккаунтах не меняет файлы сайта.
