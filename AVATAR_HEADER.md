# Задача: аватар в шапке, следящий за курсором

Инструкция для реализации. Проект — статический сайт (`index.html`, `css/`, `js/`), **не React**. Весь код ниже — ванильный JS и CSS.

---

## Что уже готово

В папке `public/` лежит файл **`avatar-orbit.mp4`**.

Это НЕ обычное видео для проигрывания. Это дорожка для техники **video scrubbing**: видео никогда не играется, вместо этого позиция воспроизведения (`currentTime`) вручную привязывается к положению курсора мыши. Персонаж на дорожке обводит взглядом полный круг, и перематывая дорожку мы заставляем его смотреть в нужную сторону.

**Характеристики файла:**

| Параметр | Значение |
|---|---|
| Разрешение | 720 × 1222 |
| Длительность | ровно 10 секунд |
| Пропорция | `720 / 1222` (≈ 0.589) |
| Цвет фона | `#4E9DCA` |
| Keyframe | каждые 5 кадров (нужно для плавной перемотки) |
| Звук | отсутствует |

**Порядок кадров по времени:** 0 сек — взгляд вправо, 2.5 сек — вниз, 5 сек — влево, 7.5 сек — вверх, 10 сек — снова вправо. Петля замкнута, первый и последний кадр совпадают.

---

## Как это работает

1. Считаем угол от центра блока с аватаром до курсора мыши
2. Переводим угол в позицию на дорожке (0…1 → 0…10 секунд)
3. Ставим `video.currentTime` в эту позицию
4. Добавляем инерцию, чтобы взгляд догонял курсор плавно, а не дёргался

Расстояние от курсора до центра не учитывается — важно только направление.

---

## Требования к вёрстке шапки

### Цвет фона — критично

Фон секции шапки **обязан быть точно `#4E9DCA`** — тем же, что зашит в видео. При совпадении цветов прямоугольник видео растворяется, и персонаж выглядит стоящим прямо на фоне шапки. При расхождении даже на пару тонов будет виден чёткий прямоугольный шов.

Никакого градиента под аватаром. Если по шапке нужен градиент — он должен быть либо очень слабым, либо начинаться правее блока с аватаром.

### Расположение

- **Аватар — слева**, текстовый блок — справа
- Ширина блока аватара: `clamp(220px, 26vw, 420px)`
- Пропорция блока строго `aspect-ratio: 720 / 1222`
- Между колонками зазор `clamp(24px, 4vw, 56px)`
- Вертикальное выравнивание по центру

Персонаж на дорожке большую часть времени смотрит вправо — то есть в сторону текста. Это осознанное решение, менять расположение на зеркальное не нужно.

### Текст справа

- Заголовок, подзаголовок, кнопка — стандартная композиция
- Текст **не должен заходить на аватар**: у видео непрозрачный фон, наложения не получится
- Ширина текстовой колонки не ограничивается жёстко, используется `minmax(0, 1fr)`

## Код

### HTML — вставить в шапку `index.html`

```html
<header class="hero">
  <div class="hero__avatar" id="avatarBox">
    <video
      id="avatarVideo"
      src="public/avatar-orbit.mp4"
      muted
      playsinline
      preload="auto"
      disablepictureinpicture
    ></video>
  </div>

  <div class="hero__text">
    <h1>Заголовок</h1>
    <p>Подзаголовок</p>
    <!-- кнопка, ссылки и т.д. -->
  </div>
</header>
```

Проверить путь к файлу: если `public/` не отдаётся веб-сервером как статика, положить `avatar-orbit.mp4` рядом с `index.html` или в `assets/` и поправить `src`.

### CSS — добавить в `css/`

```css
.hero{
  display: grid;
  grid-template-columns: minmax(0, 380px) minmax(0, 1fr);
  gap: clamp(24px, 4vw, 56px);
  align-items: center;
  padding-inline: clamp(20px, 5vw, 80px);
  padding-block: clamp(40px, 8vh, 96px);
  background: #4E9DCA;
}

.hero__avatar{
  width: 100%;
  max-width: clamp(220px, 26vw, 420px);
  aspect-ratio: 720 / 1222;
  pointer-events: none;
}

.hero__avatar video{
  width: 100%;
  height: 100%;
  object-fit: contain;
  display: block;
}

@media (max-width: 860px){
  .hero{
    grid-template-columns: 1fr;
    justify-items: center;
    text-align: center;
  }
  .hero__avatar{
    max-width: min(60vw, 300px);
    order: -1;
  }
}
```

**Про `minmax(0, 380px)`:** ноль в первом аргументе обязателен. Без него колонка не сможет ужиматься и вытолкнет соседа за край экрана на узких окнах.

### JS — добавить в `js/`

```js
(function () {
  var box = document.getElementById('avatarBox');
  var video = document.getElementById('avatarVideo');
  if (!box || !video) return;

  var DURATION = 10;    // длительность дорожки в секундах, менять только если заменили файл
  var EASE = 0.1;       // инерция: меньше — взгляд догоняет ленивее
  var PHASE = 0;        // сдвиг фазы 0…1, если взгляд промахивается мимо курсора
  var REVERSE = false;  // true, если движение зеркальное

  var still = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  var canHover = window.matchMedia('(hover: hover)').matches;

  // на тач-устройствах курсора нет — просто крутим дорожку в цикле
  if (!canHover || still) {
    video.loop = true;
    video.play().catch(function () {});
    return;
  }

  video.pause();

  var target = 0;
  var current = 0;

  window.addEventListener('mousemove', function (e) {
    var r = box.getBoundingClientRect();
    var cx = r.left + r.width / 2;
    var cy = r.top + r.height * 0.36;   // центр примерно на уровне лица

    var a = Math.atan2(e.clientY - cy, e.clientX - cx) / (Math.PI * 2);
    if (REVERSE) a = -a;
    target = (a + PHASE + 2) % 1;
  }, { passive: true });

  function loop() {
    // идём к цели по кратчайшей дуге: дорожка замкнута,
    // поэтому из 0.95 в 0.05 короче через край, а не назад через всю ленту
    var diff = target - current;
    if (diff > 0.5) diff -= 1;
    if (diff < -0.5) diff += 1;
    current = (current + diff * EASE + 1) % 1;

    if (video.readyState >= 1) {
      var t = current * DURATION;
      if (isFinite(t)) {
        video.currentTime = Math.min(DURATION - 0.001, Math.max(0, t));
      }
    }

    requestAnimationFrame(loop);
  }
  requestAnimationFrame(loop);
})();
```

## Настройка после запуска

Поводить мышью и проверить, попадает ли взгляд в курсор.

| Симптом | Что менять |
|---|---|
| Смотрит не в ту сторону | `PHASE` — перебирать от 0 до 1 шагом 0.1 |
| Движение зеркальное | `REVERSE = true` |
| Догоняет слишком резко | `EASE` уменьшить до 0.06 |
| Догоняет слишком вяло | `EASE` увеличить до 0.18 |

Менять по одному параметру за раз.

---

## Чего делать не нужно

- **Не ставить `autoplay` и `loop`** на десктопе — видео управляется скриптом, автовоспроизведение сломает эффект
- **Не сжимать и не перекодировать** `avatar-orbit.mp4` — в нём специально уплотнены keyframe, обычное сжатие их проредит и перемотка начнёт дёргаться
- **Не менять `aspect-ratio`** — пропорция должна совпадать с видео, иначе `object-fit` даст поля другого оттенка
- **Не задавать `min-height: 100vh`** для `.hero` — при узком и низком окне контент упрётся и полезет наружу
- **Не накладывать текст поверх аватара** — фон видео непрозрачный

---

## Проверка перед сдачей

1. Курсор водит по экрану — голова и взгляд следуют за ним плавно
2. Границ прямоугольника видео не видно, персонаж сливается с фоном шапки
3. Медленно сжать окно от широкого до узкого — вёрстка не ломается ни на одной ширине
4. На узком экране колонки встают в стопку, аватар сверху
5. На телефоне дорожка крутится сама по себе в цикле
6. При быстром движении мыши видео не тормозит и не рассыпается
7. Заголовок и кнопка читаются, ничего не перекрывается
