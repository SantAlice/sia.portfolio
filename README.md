# Портфолио AI-креатора — каркас

## Цвета
- `#3d84a8` — основной фон (`--blue`)
- `#e0aab9` — текст и акценты (`--pink`)
- Производные: `--blue-deep #1E4E66`, `--blue-dark #123543`, `--cream #FBF6F1`, `--ink #0B1F29`

Мелкий текст не ставим `#e0aab9` на `#3d84a8` — контраст 2.1:1, читать невозможно.
Розовый на светлом фоне = только крупный кегль. Для текстовых блоков используются
секции `.sec--deep` (тёмно-синий фон + молочный текст).

## Куда класть файлы
```
assets/photo/      фото-работы        01.jpg, 02.jpg ...
assets/video/      видео              hero.mp4, 01.mp4 ...
assets/products/   предметка          01.jpg ...
assets/other/      прочее             01.jpg ...
assets/objects/    объекты на прозрачном фоне (png) — для будущих анимаций
```

## Как заменить плейсхолдер на медиа
В разметке каждый блок-заглушка выглядит так:
```html
<div class="ph" data-slot="assets/photo/01.jpg"><span>фото · 3:4</span></div>
```
Меняем на:
```html
<img src="assets/photo/01.jpg" alt="Описание работы">
```
или для видео:
```html
<video src="assets/video/01.mp4" autoplay muted loop playsinline></video>
```
Атрибут `data-slot` подсказывает, какой файл сюда ожидается.

## Аватар в шапке (следит за курсором)
Файлы: `public/avatar-orbit-v7.mp4` (720×1076, 8.8125 сек, 423 кадра, 48 fps,
фон `#3D84A8`) и `public/avatar-poster-v7.jpg` — ровно первый кадр дорожки,
поэтому подмены постера на видео при загрузке не видно.
Аватар справа, текст слева. В покое — фронтальная поза.

Видео **не проигрывается** — скрипт вручную ставит `currentTime` по направлению
от глаз персонажа к курсору. Логика в `js/main.js`, блок 9.

Покрыта дуга **313° → 0° → 245°** (0 вправо, 90 вниз, 180 влево, 270 вверх).
Верхний сектор **245–313°** в дорожке отсутствует: там персонаж возвращается
в нейтраль настоящими кадрами исходника.

Чего нельзя делать:

1. **Менять `--hero-bg`.** Он равен `--blue` `#3D84A8`. Фон внутри mp4 записан
   не ровно этим цветом, а на пару единиц синее, и файл размечен BT.709/limited
   range — после декодирования браузер рисует нужный цвет. Под другой цвет фон
   в видео надо перезаписывать, подгонкой CSS это не лечится.
2. **Пережимать mp4.** Перекодирование без тех же флагов сдвинет цвет фона
   и вернёт видимый прямоугольник вокруг аватара.
3. **Вшивать видео как `data:` URI.** Только обычная ссылка на файл — иначе
   страница ждёт разбор нескольких мегабайт base64 и теряет кеширование.
4. **Возвращать сглаживание к постоянному шагу.** В `loop()` шаг считается от
   `dt`: на 120 Гц голова догоняет курсор с той же скоростью, что на 60 Гц.
   Плюс `currentTime` не трогается, пока смещение меньше `STEP` — без этого
   браузер пересобирает кадр впустую и появляются микрорывки.
5. **Трогать `MAP`, `eyePoint()` (0.482 / 0.184), кратчайшую дугу в `loop()`
   и разворот `if (u < 245) u += 360`.**

Секция с аватаром обязана иметь фон `--hero-bg` на всю ширину блока с видео.

Контрольные точки: справа — 1.816 сек, снизу — 3.823, слева — 5.531,
вверх-вправо — 1.011, сверху — нейтраль (0.000).

Моргание в районе 5°–18° — закрытые глаза в исходнике, не чинится.

Подстройка (менять по одному значению, `js/main.js`):

| Симптом | Что менять |
|---|---|
| Догоняет вяло | `EASE` увеличить до 0.15–0.2 |
| Догоняет резко | `EASE` уменьшить до 0.06 |
| Видны ступеньки при медленном движении | `STEP` уменьшить до `1/192` |
| Взгляд не доходит по всей дуге | левая колонка `MAP` — сдвинуть все углы |
| Промах в одном секторе | соседние узлы `MAP` этого сектора |
| Промах зависит от близости курсора | `0.482` и `0.184` в `eyePoint()` |

На тач-устройствах и при `prefers-reduced-motion` дорожка крутится в цикле.

## Что уже работает
- аватар в хиро, следящий за курсором (video scrubbing)
- фиксированная шапка с изменением фона при скролле + полоса прогресса
- последовательное появление хиро при загрузке
- появление блоков по скроллу (IntersectionObserver)
- бегущая строка с девизом
- направления как раскрывающиеся строки: клик по строке открывает блок с работами
- кнопки «раскрыть все» / «свернуть все»
- ссылка вида `index.html#video` сразу открывает нужное направление
- счётчики цифр
- смета: строки вычёркиваются при попадании в экран
- аккордеон FAQ
- мобильное меню
- поддержка prefers-reduced-motion

## Как добавить направление
Скопировать один блок `<div class="drow" data-key="...">` в `#dirs`, поменять
номер, название, счётчик, описание и плитки внутри `.dgrid`. Количество
направлений не ограничено — строки просто продолжают список.

## Что дальше
Каркас нейтральный — под него подключается механика выбранного направления
(портал, грибница, диптих, горизонтальная раскадровка и т.д.).

## Запуск
Открыть `index.html` в браузере. Локальный сервер не нужен.
