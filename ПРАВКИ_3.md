# Правки 3: пропорции шапки

Причина расхождения с утверждённым макетом — арифметическая, не смысловая.
Макет рисовался на окне 1440 px, реальный экран 1897 px. Все три размера в
задании ограничены сверху жёсткими пикселями, и на широком экране эти потолки
срабатывают раньше, чем `vw`:

| | доля в макете (1440) | доля сейчас (1897) |
|---|---|---|
| панель | 42% = 600 px | **32.7%** — упёрлась в `max 620px` |
| заголовок | 5.5vw = 79 px | **78 px** вместо 104 |
| навигация | 2.1vw = 30 px | **30 px** вместо 40 |

Блок съёжился примерно на четверть относительно кадра. Плюс в прошлых правках я
усилила затемнение стекла, и панель стала читаться плотной карточкой вместо
лёгкой вуали, как было в макете.

## Что поменять

```css
.hero__nav a {
  font-size: clamp(24px, 2.1vw, 34px);      /* было max 30px */
}

.hero__panel {
  width: clamp(320px, 42vw, 730px);          /* было max 620px */
}

.hero__title {
  font-size: clamp(2.1rem, 5.5vw, 92px);     /* было max 78px */
}

/* вернуть лёгкое стекло — как в утверждённом макете */
.hero__glass {
  background:
    linear-gradient(180deg, rgba(255,255,255,.16), rgba(255,255,255,0) 46%),
    linear-gradient(180deg, rgba(10,38,54,.20), rgba(8,30,44,.42));
}
```

Полностью пропорциональное увеличение (40 / 800 / 100) я проверила — выходит
перебор: навигация забирает на себя всё внимание и наезжает на ладонь. Значения
выше это середина между нынешним состоянием и полной пропорцией. Эталон —
`вариант_середина.png`, снят на твоём размере окна.

## Подзаголовок — сократить до одной строки

В макете была одна короткая строка, в задании я развернула её до двух, и блок
стал грузнее. Вернуть:

```html
<p class="hero__sub">AI-визуал и видео для брендов</p>
```

Фразу про 48 часов перенести на следующий экран — в шапке она не работает,
потому что читается уже после заголовка и кнопок.

## Проверить

1. На 1897 px панель занимает около 38–39% ширины секции, не 33%.
2. Правый край панели не доходит до лица: замерить, где начинаются волосы, и
   убедиться, что зазор не меньше 40 px.
3. Заголовок по-прежнему в две строки на всех ширинах 360–2560.
4. Панель читается как лёгкая вуаль, сквозь неё видно ладонь, а не как
   непрозрачная карточка.
5. Контраст подзаголовка на панели остался ≥ 4.5:1 — после осветления стекла
   перепроверить, это единственный элемент, где порог реальный.
